📋 安装步骤（安卓）

  1. 点击上方「安卓 Android」下载 APK 文件
  2. 下载完成后点击安装
  3. 如果提示「未知来源应用」，点击「允许」
  4. 打开 App，点击「启动服务」
  5. 授权拨号权限和通知权限
  6. 记下 App 显示的 IP 地址
  7. 在电脑端软件中输入该 IP，点击连接
  8. 连接成功后即可一键拨号 🎉
