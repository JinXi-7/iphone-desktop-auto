📋 安装步骤

  1. 手机：下载并安装对应 App，打开后点「启动服务」
  2. 手机：授权拨号权限和通知权限，记下显示的 IP 地址
  3. 电脑：下载并打开电脑端软件
  4. 电脑：在界面输入手机 IP，点「连接」
  5. 电脑：导入 Excel 电话表或手动添加联系人
  6. 点击联系人或历史记录的拨号按钮，手机自动拨号 🎉

⚠️ 手机和电脑需连接同一个 WiFi 网络
